## 1. Positioning

**Tagline Options:**
- "Tax Smart. Borrow Smart."
- "Your AI-Powered Tax & Credit Intelligence"
- "The Platform for Financial Clarity"

**Core Value Proposition:**
An API-first AI platform that bridges tax compliance and creditworthiness — helping Nigerians understand their taxes and access fair financial services.

**Differentiation:**
- No Nigerian tax platform has a proper API for developers
- No product combines tax compliance + credit scoring under one roof
- First mover on the "tax health → credit score" insight

---

## 2. Target Audiences

### Primary: Nigerian Tech Developers
- Age 22-35, urban (Lagos, Abuja, Port Harcourt)
- Active on Twitter, members of DevC, GDG communities
- Looking for APIs to integrate into their products
- Pain: No Nigerian tax API exists

### Secondary: Tax Professionals & Accountants
- Age 28-50, run consultancies or work in firms
- Pain: Manual processes, no digital tools, compliance headaches
- Opportunity: Marketplace to find clients

### Tertiary: Nigerian SMEs
- Age 30-50, founders/finance leads
- Pain: Confused by NTA 2023 changes, need help with compliance
- Opportunity: Simple tools + access to verified tax pros

## 3. Content Strategy (Twitter-First)

### Content Pillars

| Pillar | Description | Frequency |
|--------|-------------|-----------|
| **Tax Education** | Explain NTA 2023 changes in plain terms | 3x/week |
| **API Demos** | Show what the API can do with code snippets | 2x/week |
| **Credit Tips** | Financial literacy, credit health, practical advice | 2x/week |
| **Behind the Scenes** | Building in public, tech choices, learnings | 1x/week |
| **Social Proof** | Waitlist numbers, early signups, partnerships | 1x/week |

### Content Formats

```
Educational:
├── Thread: "5 things the new Tax Act means for you"
├── Single tweet: "Did you know? Your tax filing history affects your credit score"
├── Infographic: Tax brackets visual explanation
└── Carousel: "How to calculate your VAT in 4 steps"

API Demos:
├── Code snippet: "Calculate income tax in 3 lines of code"
├── Thread: "Built a tax calculator with our API in 10 minutes"
├── GIF: API response demo
└── Carousel: API quickstart guide

Engagement:
├── Poll: "What's your biggest tax headache?"
├── Quote RT: Interesting tax stats
└── Reply Chain: Answer tax questions
```

## 4. Launch Motion

### Phase 1: Pre-Launch (Weeks 1-4)

```
Goal: Build anticipation, capture waitlist

Week 1-2:
- Announce: "Building the missing tax API for Nigeria"
- Thread: Explain the problem (no Nigerian tax API exists)
- SuperScale: Product mock-up of developer dashboard

Week 3-4:
- Thread: "How we built our credit scoring using tax data"
- SuperScale: Explainer video (60-90 sec)
- Waitlist launch: "Get early access"
- Poll: "What would you use a tax API for?"

Traction metrics:
- Waitlist signups: 100 by end of week 4
- Twitter followers: +200
```

### Phase 2: Soft Launch (Weeks 5-8)

```
Goal: Get first users, gather feedback

Week 5-6:
- API docs go live
- Invite waitlist to beta
- Thread: "We launched. Here's what we built."
- SuperScale: Product demo video

Week 7-8:
- Case study: First developer integration
- Thread: "First week learnings"
- Introduce: Tax Professional Marketplace preview
- Poll: "Want to find verified tax pros near you?"

Traction metrics:
- 10 beta developers
- 3 tax pros signed up
```

### Phase 3: Public Launch (Weeks 9-12)

```
Goal: Official launch, press, growth

Week 9-10:
- Press release / media outreach
- SuperScale: Full explainer video
- Launch announcement thread
- Partner announcement (Mono integration)

Week 11-12:
- Marketplace goes live
- Developer community outreach (DevC, GDG)
- Case studies from early users

Traction metrics:
- 50 developers
- 20 tax professionals
- First revenue ($500+)
```
