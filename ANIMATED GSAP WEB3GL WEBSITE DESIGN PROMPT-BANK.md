How to use this pack


Each level is a complete, standalone brief. You do not need the level before it.

1.  Pick the level you actually need.

2.  Paste the shared foundation first, then the level brief.

3.  Run the acceptance proof before you accept the build.  
Every level ends with one. It is a pass or fail test, not an opinion. If it fails, the build is not done.


4.  When it misses, revise the brief with the gap you observed.  Not “make it better.” Name the specific behaviour that was missing and add it to the brief as a requirement.

What this document is, and is not

These are curated build briefs documenting an iterated implementation. They are detailed standalone briefs a builder could use to reproduce the intended features. They are not proof of ten independent single-prompt model runs.

This was an Astra-directed mixed-model build. GPT-5.6 Luna handled bounded CSS and site functionality. GPT-5.6 Sol handled the presentation hub and this prompt pack.

The foundation

Safe by default


Every brief in this pack inherits the five rails below, unless a level deliberately starts simpler. They are the reason these sites can be handed to a stranger.
Paste this section above whichever level brief you are running.

1.  Portable semantic HTML, CSS and JavaScript with no backend, API key, analytics, external fonts or runtime network dependency.

Why it matters:  Nothing to breach, nothing to bill, and nothing that breaks when a third-party service changes.

2.  Local Inter and Instrument Serif fonts, supplied AUREL architectural images, visible keyboard focus, meaningful alt text and responsive layouts without horizontal overflow.

Why it matters:  The page works offline, and it works for someone navigating by keyboard or screen reader.

3.  prefers-reduced-motion support, honest empty, loading and fallback states, and fictional-property disclaimers.

Why it matters.  Motion never traps anyone, and the page tells the truth when it has nothing to show.

4.  Viewing inquiries create a local text draft only.
Nothing is transmitted and no appointment is booked.

Why it matters.  No form harvests a stranger's data. The visitor keeps their own information.

5.  Saved selections stay in that browser via local storage and do not imply an account, reservation or purchase.

Why it matters.  Persistence without a database, and without a promise the business cannot keep.


Rail four does the most work

A form that collects a name, an email and a preferred date is the single riskiest thing on most small business websites. Rail four keeps the interaction and removes the liability entirely.

The visitor fills in the form. The browser writes them a text file. Nothing leaves their machine, so there is no inbox to secure, no database to breach and no consent notice to get wrong.

<script>
const canvas = document.getElementById("hero-canvas");
const context = canvas.getContext("2d");

const FRAME_COUNT = 300;

const currentFrame = (index) =>
  `./assets/img_seq/${index}.png`;

const images = [];
const imageSequence = {
  frame: 1,
};

function resizeCanvas() {
  canvas.width = window.innerWidth;
  canvas.height = window.innerHeight;
  render();
}

window.addEventListener("resize", resizeCanvas);

for (let i = 1; i <= FRAME_COUNT; i++) {
  const img = new Image();
  img.src = currentFrame(i);
  images.push(img);
}

images[0].onload = () => {
  resizeCanvas();
};

function drawImageCover(img) {
  if (!img) return;

  const canvasRatio = canvas.width / canvas.height;
  const imageRatio = img.width / img.height;

  let renderWidth;
  let renderHeight;
  let x;
  let y;

  if (imageRatio > canvasRatio) {
    renderHeight = canvas.height;
    renderWidth = img.width * (renderHeight / img.height);

    x = (canvas.width - renderWidth) / 2;
    y = 0;
  } else {
    renderWidth = canvas.width;
    renderHeight = img.height * (renderWidth / img.width);

    x = 0;
    y = (canvas.height - renderHeight) / 2;
  }

  context.clearRect(0, 0, canvas.width, canvas.height);

  context.drawImage(
    img,
    x,
    y,
    renderWidth,
    renderHeight
  );
}

function render() {
  const image = images[Math.round(imageSequence.frame) - 1];

  if (!image) return;

  if (image.complete) {
    drawImageCover(image);
  }
}

let targetFrame = 1;
let currentFrameSmooth = 1;

function animate() {
  currentFrameSmooth +=
    (targetFrame - currentFrameSmooth) * 0.08;

  imageSequence.frame = currentFrameSmooth;

  render();

  requestAnimationFrame(animate);
}

animate();

window.addEventListener("scroll", () => {
  const section = document.querySelector(".hero-sequence");

  const scrollTop =
    window.scrollY - section.offsetTop;

  const maxScroll =
    section.offsetHeight - window.innerHeight;

  const progress = Math.min(
    Math.max(scrollTop / maxScroll, 0),
    1
  );

  targetFrame =
    1 + progress * (FRAME_COUNT - 1);
});

document.fonts.ready.then(() => {
  resizeCanvas();
});
